-- 4. THE RED CHECK: THIS SUITE CAN GO RED --

A green equivalence suite is worth nothing until it is shown it can fail, and
this front has already been bitten by exactly that. CORRECTED 2026-07-30: an
earlier version of this paragraph said robo_pilot_tests records a first red
check left green because moving a constant by one unit was absorbed by integer
division. That is not what it records. What it records is that a red check
found the suite BLIND: swapping the channel blocks failed 5 tests and mistyping
the own_speed shift failed 1, but mistyping TANK_R from 4608 to 4680 PASSED
EVERYTHING, because the fixture stood in open ground where clearance exceeds
WALL_SPAN, wall_danger saturates to a silent zero and the radius cancels out
entirely. A near-wall fixture was added to close it.

robo_pilot itself is never touched. Each row below is a COPY of it, renamed and
corrupted in one named place, compiled to a scratch directory and pointed at by

     an earlier version of this line called 4068 the transposition

-- 5. WHAT THIS DOES NOT PROVE --

Equivalence is established ON THE STATES THESE 3200 MATCHES VISIT, against the
predictive_gun floor bot, for arm S genomes of topology [17,12,5]. That is the
endpoint the front reports, so it is the right target, but it is not a proof over
all inputs. A defect reachable only from a state no arm S champion drives into
against this one opponent would survive this test. Part A's per-turn state
comparison narrows that gap and does not close it.

STILL STRANDED IN THE RUNNER, and it is the extraction that matters most: the
120-start generator with its measured heading-offset correction, and the
train/held-out/calibration split. robo_match:starts/0 in the engine returns SIX
hand-written starts, which this research superseded. Two hosts disagreeing on the
start set produce results that cannot be compared, so a foreign genome scored
against engine starts is not scored against these numbers. robo_pilot being
faithful does NOT make the mesh half of this front runnable on its own.

ONE CHANGE WAS MADE TO THE RUNNER and it is named here rather than left in a
diff: a single -export line was added to
experiments/exp066_single_population_floor_tests.erl so this replay could call
the runner's OWN pilot_act/4, pilot_init/0, channels/2, heldout/3, rates/1 and
win_rate/1. No body was touched and no constant moved. A test that instead
re-copied those bodies into a third file would have been comparing a copy against
a copy, which is the exact failure it exists to detect.
